## 一、课程原意的结构定义

头肩底是出现在一段**明显下跌趋势之后**的阶段性底部、由跌转涨的看涨结构。它由四个部分构成：

1. 左肩；
2. 头部；
3. 右肩；
4. 颈线。

### 三个低点与时序

按时间顺序，结构为：

`A（左肩低点） → P1（A 后反弹高点） → L（头部最低点） → P2（L 后反弹高点） → B（右肩低点） → 向上突破颈线`

- **硬条件**：`L < A` 且 `L < B`，即头部 L 必须是三个低点中最低者。
- A 与 B 谁高谁低不重要；通常接近同一水平、差异很小更理想。
- 若 A 或 B 低于 L，则不构成标准头肩底。
- 识别起点：一段下跌中出现三个阶段性低点，且中间低点最低，可列为头肩底候选观察；只有两个低点的是 W 形，不是头肩底。
- 时间尺度：课程建议完整结构至少约 **20 个交易日 / 一个月**；一周内来回波动不应认定为头肩底结构。

### 颈线的文字化定义

颈线连接：

- A 低点反弹后的高点 `P1`；
- L 低点反弹后的高点 `P2`。

因此它是一条随时间变化的直线 `neckline(t)`，可以向上、向下或近乎水平。`P2 < P1` 时是向下倾斜颈线；课程称其在成本/缓冲角度通常更有利，但**不是结构成立的硬条件**。`P2 > P1` 的上倾颈线会让突破观察更滞后，却仍可形成头肩底。

## 二、成交量：强弱证据，而非排除条件

## PPT 留档 02｜低点与成交量（视频约 10:11）

### PPT 原文

```text
低点：
L低于A和B。
A和B谁低不重要。

成交量：
L和B低点开始的反弹
上涨成交量，大于左肩
A低点的反弹成交量。
```

### 右侧K线图的文字化理解

- 图再次强调三个低点的相对关系：左肩 A 与右肩 B 可以不等低；唯一硬高度关系是头部 L 必须低于两者。
- 比较的不是低点当天单根K线的成交量，而是分别从 `A`、`L`、`B` 三个低点启动的**反弹上涨阶段**的成交量。
- 红框圈出 B 后向上穿越上倾颈线附近的一组上涨K线，以及对应的一组显著放大的成交量柱；红箭头指向其后的上行延续。这张图把“B后反弹量能增强”作为突破强度的正面证据。
- 可程序化时，应比较三个反弹区间的上涨量能（如上涨日成交量分布、区间均量/累计量），而非只以某一根突破K线或整体20日均量代替。课程本页没有给出明确计算窗口或阈值，不能自行制造固定倍数门槛。

### 本页可程序化字段

```text
low_order_check = (L.low < A.low) and (L.low < B.low)
A_vs_B_low = unrestricted  # A、B谁低不重要，但都必须高于L
rebound_volume_A = volume_context(A -> P1)
rebound_volume_L = volume_context(L -> P2)
rebound_volume_B = volume_context(B -> neckline_cross / next rebound high)
volume_strength = strong if rebound_volume_L/B > rebound_volume_A; neutral if equal; weaker if below
illustrated_evidence = B-side advance near neckline with relative volume expansion
```

### 字幕与PPT的口径备注

PPT本页的原文使用“**大于**”；字幕约 08:05 处另说“如果持平的话其实也可以”。用户补充确认：**成交量是次要的强弱辅助条件，持平也可以**。因此，本期生效的学习口径为：L、B反弹量高于A反弹量可增强头肩底质量；持平可接受；低于A只降低强度并提示量能不理想，均不得单独否定已满足价格结构与颈线突破确认的头肩底。

课程描述的较强量能组合：

- 自 L、B 低点向上的反弹成交量，通常高于自 A 低点向上的反弹量；持平亦可接受；
- 反弹上涨段的量能越大、右侧反弹越强，结构越强；回踩时缩量更理想；
- 向上穿越颈线时成交量快速放大，是有效突破的更强证据。

这些是**质量/置信度**特征，非形态的硬否决门槛。量能没有完全符合时，应标为较弱候选或较弱确认，而不是仅凭成交量否定已满足价格结构的头肩底；持平本身可接受。

## 三、突破、有效性与状态演变

## PPT 留档 03｜买点与卖点、颈线的 3% 有效性（视频约 14:10）

### PPT 原文

```text
买点与卖点：

B点上涨，接近颈线
位置，可以卖出（压力）。

突破颈线，可以买入。
```

### 用户补充的本期核心量化口径

用户确认：**突破或跌破颈线达到 3% 才是最稳妥的课程操作确认。**

把它转为不含操作指令的结构规则：对每个交易日按该日的颈线值 `neckline(t)` 计算相对偏离：

```text
deviation(t) = (price(t) - neckline(t)) / neckline(t)

deviation > +3%  -> 颈线有效上破 / 头肩底上行确认增强
deviation < -3%  -> 已上破结构的假突破 / 重新受颈线压制
-3% <= deviation <= +3% -> 仅为颈线附近交互，尚不作最稳妥的有效突破或失败确认
```

- B 后反弹到颈线附近、但尚未有效上破：`neckline_resistance_test`，即课程所称压力状态。
- 只有偏离颈线向上超过 3%，才进入 `effective_neckline_upward_break` 状态。
- 上破后若再向下偏离颈线超过 3%，进入 `failed_neckline_breakout` 状态；它表示本轮头肩底上破未维持，不自动推断更大级别趋势。
- 课程截图及字幕没有明确 `price(t)` 要固定为收盘、盘中、最高或最低价；该歧义保持留档，正式写入 RaModel 前不得自行补成某一种价位。若用户后续明确，以用户口径覆盖。
- PPT 中“可以买入/可以卖出”只作为课程原话保留；正式 RaModel 只能报告以上结构状态和可审计的 3% 数值，不能生成交易指令。

### 课程给出的两层状态

1. **候选/未突破**：A、L、B 和颈线已经可画出，但价格未上穿颈线；颈线表现为压力区域。
2. **向上突破**：价格穿越颈线；课程以突破时放量作为更强的有效性证据。

课程进一步给出量化缓冲：以颈线的上下 **3%** 观察趋势有效性；用户指定它是本期最重要、最稳妥的量化确认尺度。

- 高于颈线超过 3%：可记为“有效向上突破/上行确认增强”；
- 已上穿后又低于颈线超过 3%：可记为“假突破/突破失败，重新受颈线压制”。

> **待 PPT 截图核实的口径**：本期文字稿对“价格上穿/下穿”“偏离 3%”未明确限定为收盘价、最高/最低价或盘中价。正式写入时不得擅自采用第40期头肩顶的“日K收盘价”口径，除非本期 PPT 或用户补充明确该口径。

### 课程中有关“买卖点”的原话所对应的中性状态

- B 之后反弹、首度触及并未站稳颈线：`neckline_resistance_test`；
- 上穿后回踩颈线但仍维持在其上：`neckline_retest_after_break`；
- 突破失败并低于颈线超过 3%：`failed_breakout_below_neckline`。

这些名称仅描述图表状态，不构成任何买入、卖出、止损、仓位或价格目标建议。

## 四、最小上行测量（课程表述）

课程把头肩底形成后的最小涨幅定义为：

`height = neckline_at_breakout − L_price`

即从头部最低点 L 到突破处颈线的**垂直距离**；课程用相同的点数作为向上的最小测量距离。

RaModel 正式版应只呈现为“课程测量高度 / 历史结构参考”，不把它生成未来价格目标或交易建议。

> **待核实**：文字稿未说明 L 应使用影线最低价、实体下沿或收盘价；PPT 若给出图示/文字，以 PPT 为准。

## 五、适用性与局限（课程内容）

- 技术形态是概率性历史统计，不是 100% 的预测工具；基本面突发变化也可能使技术面失真。
- 流动性和成交额较高的大盘标的，课程认为形态更容易形成市场共识；低流动性、小成交额标的更容易失真。
- 以上为课程的适用性说明，不能当作未来表现保证。

## 六、案例卡 01｜美国钢铁 X：向下倾斜颈线的头肩底

**来源**：文字稿约 21:06–26:35；视频案例截图约 25:17；标的显示为 `X 美国钢铁`，日K，横轴约 2019 年 10 月至 11 月。

### 图形译码

1. 先有一段从约 `13` 一带向下回落的背景。
2. 出现三个阶段性低点：左肩 `A`、最低头部 `L`、右肩 `B`。原图可读出头部低点标注 `L = 9.837`。
3. A、B 均在约 `10` 一带；`L = 9.837` 低于两者，符合“头部最低、双肩无需等低”的关系。
4. A 后反弹高点 `P1` 约在 `12.3` 一带，L 后反弹高点 `P2` 约在 `11.5` 一带；`P2 < P1`，故 P1—P2 所连颈线为**向下倾斜**。
5. 视频中的红色线和箭头为讲解标注：斜向下的线延长 P1—P2 的颈线；水平线强调 A/B 附近的相近低点；红箭头分别指出 A、L、B、反弹高点和随后上穿颈线的路径。它们不是原始K线/指标数据。
6. B 后价格上行，穿越下倾颈线；其后出现更大幅的上行，图中可见阶段高点标注约 `13.691`。
7. 图中右侧上破段有一根明显放大的绿色成交量柱，是突破强度的佐证；成交量按本期口径仅作辅助，不单独决定头肩底是否成立。
8. 课程文字稿称上穿后曾有连续两日回踩、随后继续上行；截图本身不足以逐日锁定那两根回踩K线，故该细节以字幕记录为准。

### 不依赖图片的字段

```text
symbol = X (United States Steel)
context = prior downtrend; duration >= about one month
anchors = A_low (~10), P1_rebound_high (~12.3), L_low (9.837), P2_rebound_high (~11.5), B_low (~10)
relations = L_low < A_low; L_low < B_low; A_low ≈ B_low
neckline = line(P1_rebound_high, P2_rebound_high), slope < 0
path = breakout -> two-day neckline retest (subtitle evidence) -> continued rise toward shown ~13.691 high
volume_context = visibly expanded green volume on later upside break; secondary-strength evidence
```

## 七、案例卡 02｜通用汽车 GM：上倾颈线、突破后的反复贴线

**来源**：文字稿约 19:41–21:06；PPT/视频案例截图约 20:23；标的显示为 `GM 通用汽车`，日K，横轴可见约 2020 年 6 月至 8 月。

### 图形译码

1. A 前，图中价格先从约 `31` 一带回落，形成该头肩底需要的下行背景。
2. 形成左肩低点 `A`，随后反弹到第一个高点 `P1`。
3. 再次回落形成头部低点 `L`；图中 L 明显低于 A 与 B。课程此前的示意图把 L 标作 `23.330`，但本张案例图无法可靠判定该数字是否仍是同一根K线的最低价，故不把它当作本例精确锚点。
4. L 反弹到第二个高点 `P2`；P2 高于 P1，因此连接 P1、P2 的颈线向上倾斜。
5. 后续回落形成右肩低点 `B`；B 高于 L。A、B不要求等低。
6. B 后上行穿越上倾颈线。图中青色箭头标出颈线附近的突破段，右下方青色箭头标出对应的显著成交量柱；这构成突破强度的量能背景。
7. 突破后，价格在颈线上方延续上行；字幕补充该案例曾在颈线上方反复贴线、未向下偏离 3%，达到课程最小测量高度后，后续应按新结构重新观察。

### 不依赖图片的状态时序

```text
prior decline
  -> A_low
  -> P1_rebound_high
  -> L_low (L < A and L < B)
  -> P2_rebound_high (P2 > P1)
  -> B_low
  -> upward cross of rising neckline
  -> relative-volume expansion at breakout
  -> continuation / later reclassification as a new structure
```

### 本例对规则的校准

- 头肩底可以有**上倾颈线**，因此不能用“颈线不是水平或下倾”否定该形态。
- 上倾颈线意味着随时间需要越过的颈线价位变高；实际核验必须计算 `neckline(t)`，不能固定使用 P1 或 P2 的静态价格。
- 本例用来说明 3% 口径：在颈线上方附近的来回摩擦、但未下偏超过 3%，不应草率标为失败；向下偏离超过 3% 才进入“上破失败/重新受压”的课程状态。
- 成交量仅强化突破解释，不能替代 A、L、B 和颈线的价格结构检验。

### 不能从文字稿确定的内容

- A、L、B 的精确日期与价格；
- 使用哪根 K 线/哪一种价位计算 3%；
- 成交量的精确数字。

## 八、结课写入摘要（用户确认）

本期已按用户授权写入 RaModel，且**仅作用于 `head_shoulders_bottom_assessment`**，不修改或迁移至头肩顶、M顶、W底、杯柄或任何其他模型。写入内容包括：

- 下跌趋势中以 `A → L → B` 三个主要低点作快速初筛；该三点关系只是寻找候选的捷径，不取代 `P1 → P2` 颈线。
- 完整五枢轴、`L < A` 且 `L < B`、约20个交易日/一个月的成熟度、以及P1/P2上倾/下倾/近水平颈线。
- 成交量是次要强弱条件：L/B反弹量大于A更强，持平可接受，较低仅降级。
- 相对颈线超过 `+3%` 的有效上破增强、已经上破后低于 `-3%` 的假突破/重受压，以及中间±3%交互带。
- 课程未规定3%使用收盘、最高、最低或盘中价；模型因此必须报告所用口径及可得的 close/high/low 偏离，不擅自将第40期的收盘规则搬入。
- 只记录L至突破日颈线的结构高度与案例校准，不输出任何交易行动、价格目标、止损或仓位。

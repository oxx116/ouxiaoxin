# 第41期学习草稿：M顶（双重顶）

> 状态：已完成；第41期规则已审核并并入 `ramodel_prompt.py` 的生效 RaModel 规则。
>
> 优先级：本页PPT及用户当场补充的口径优先于字幕文字稿；文字稿只用来补足PPT没有写明的定义。

## PPT 原文逐字转写｜M顶构成5要素

1. **出现于一段明显的上涨趋势中。**
2. **运行方式，股价涨至某一位置A高点，出现至少10%的回撤，下跌至L低点，随后开始反弹，
   当反弹至A高点价格附近时，再次滞涨形成B高点，随后再次下跌，跌破颈线，形成M型。**
3. **A点到B点，周期越长越好，一个月以上比较有效。**
4. **B点通常比A点略低（不要低于5%）或持平，但偶尔发生B点高于A点的情况，不高于3%，极
   限不超过5%。**
5. **价格跌颈线（以收线为准），即L低点价格，形成M顶。**

## 用户补充的精确定义（硬口径）

1. 第2点的“至少10%回撤”只比较两根极值K线的**收盘价**：A高点K线的收盘价与L低点K线
   的收盘价，不能用上下影线极值替代。

   ```text
   retracement_pct = (A_peak_candle.close - L_trough_candle.close)
                     / A_peak_candle.close × 100%
   retracement_pct >= 10%
   ```

2. 第5点的“收线”就是该后续日K的**常规时段收盘价**。盘中或影线穿过颈线、但收盘没有在
   颈线下方，不算确认跌破。

## 转换为可核验的结构语言

### 1. 前置环境

- A点前必须是明确上行趋势；普通横盘、仅一两日小波动，不能充当M顶的前置趋势。

### 2. A—L—B 的时序与回撤

- 先有峰值 A；再回撤至谷值 L；之后反弹至接近 A 的第二个峰值 B。
- A→L 的回撤必须至少约10%。该百分比**仅**由 A峰值K的收盘价和L谷值K的收盘价计算。
- “接近A高点”不是要求A、B绝对相等；具体容差由第4点约束。

### 3. A到B的时间成熟度

- A→B 的间隔越长，课程认为结构越有效；一个月以上为“比较有效”。
- 这是一项成熟度/强度条件。若时距明显很短，应标为时间不足或较弱候选，不能把一般日内或
  数日波动直接叫作M顶。

### 4. 双顶高度容差

- 通常 B 略低于 A 或与 A 持平；B不得低于A约5%。
- B偶尔可高于A：通常不高于约3%，绝对极限不超过约5%。超过5%时，应优先审视是否是新的
  强上升趋势而非M顶。
- 这一项比较的是两个峰值位置的高度；与第2点“10%回撤只用收盘价”是两个不同的计算口径。

### 5. 颈线与确认

- M顶只有一个中间谷值 L，因此颈线是**经过L低点的水平线**，不是头肩顶那种连接两个回撤
  低点的斜线。
- 课程字幕对“L低点价格”的补充：以L的完整低点（含下影线）作为颈线价格；确认K必须以其
  常规时段收盘价收在该水平下方，即 `later_close < L.low`。
- 仅盘中／影线刺破L低点、收盘拉回其上方，属于测试而非确认；收盘严格低于L低点，M顶确认。

## 不以成交量作为形成门槛

- 本期明确：M顶下行没有明确的成交量硬要求；识别以结构和关键颈线的价格关系为准。
- 放量跌破可作为趋势更明显的背景证据；关键位置的缩量下跌也可能是真下跌。因此量能不能用来
  否定已满足结构与收盘确认条件的M顶。

## PPT 原文逐字转写｜M顶形成后的最小跌幅测算

**以AB两点，取较小值，到颈线的垂直距离。**

### 转换为可核验的结构语言

- 先在两个峰值 A、B 中选取价格较低的那个：`P_ref = min(A_peak_price, B_peak_price)`。
- 再测量该较低峰值到颈线的**垂直距离**：

  ```text
  minimum_measurement_height = P_ref - neckline_price
  ```

- 本期M顶的颈线是经过 L 低点的水平线，因此 `neckline_price = L.low`；在这一水平颈线的
  前提下，上式等同于 `min(A_peak_price, B_peak_price) - L.low`。
- “最小跌幅”是课程提供的**结构量度高度**，只在M顶已按收盘跌破颈线后作为观察尺度；它不是
  对未来价格的保证，也不应换算、输出为目标价或操作指令。
- 此处A/B使用峰值价格，与第2点“10%回撤只用A、L两根K的收盘价”分属不同口径，不能混用。

## 案例卡 01｜美国钢铁 X：A—L—B 的标准M顶确认

**来源**：会员第41期视频，16:11处截图；标的显示为 `X 美国钢铁`，日K，横轴约为2018年
5月至8月。图中已明确标出 A、L、B。

### 按图理解结构

1. **前置上行**：A之前，价格由约31.7一带爬升至36—38一带，主要峰谷向上，符合本期所说
   的上行背景，而不是短周期横盘。
2. **A（左侧峰值）**：图上标注的A位于左侧高点，旁边可见的K线最高价标注为 `38.376`。
   这是图示峰值；第2要素的10%回撤须另取该A峰值K的**收盘价**计算，不能直接用38.376替代。
3. **L（中间谷值／颈线锚点）**：A后价格下行至图中标注L的中部低点，随后止跌反弹。以L的
   完整低点（含下影线）画出水平颈线。
4. **B（右侧峰值）**：L后价格反弹形成B。B低于A，但视觉上仍处在A高点附近，符合“通常略低、
   不宜低于A约5%”的双顶高度关系；A到B跨越约两个月，也符合“一个月以上比较有效”。
5. **确认**：B后价格转跌；右侧出现一根实体很长的阴线，其常规收盘明显落在L水平颈线下方，
   因此这不是仅有A—L—B外观的候选，而是**已按收盘确认的M顶**。
6. **确认后的演化**：颈线被收盘跌破后，价格继续快速下行，图中随后低至约28.9一带。这是课程
   “结构确认后下行延续”的历史示例，不是未来价格保证。

### 与规则逐项对应

| 要素 | 本例证据 | 结论 |
| --- | --- | --- |
| 明显上行趋势 | A前由约31.7上行至36—38区域 | 通过 |
| A→L 回撤至少10% | 课程讲解口述该段回撤为13.87%；截图无法读出两根K的收盘价 | 通过；部署时仍须以收盘数据复算 |
| B接近A | B略低于A、未见明显脱离 | 通过图形关系；数值须由峰值数据复核 |
| A→B周期 | 约2018年5月至7月 | 超过一个月，较有效 |
| 收盘跌破L颈线 | 大阴线实体收盘位于L水平线下 | 已确认；非影线刺破 |
| 成交量 | 破位大阴线附近量柱显著放大 | 仅作增强背景，不是成立门槛 |

### 量度字段留档

```text
structure = A → L → B
neckline = horizontal line through L.low
confirmation = first later regular close < L.low
measurement_reference = min(A_peak_price, B_peak_price)
minimum_measurement_height = measurement_reference - L.low
```

本截图不具备每根K的完整OHLC数据，因此不伪造 A.close、L.close、L.low 或量度数值；云端模型
拿到原始日K后应按上述字段复算。

## 案例卡 02｜雪佛龙 CVX：M顶候选未确认，颈线验证为支撑

**来源**：会员第41期视频，24:40处截图；标的显示为 `CVX 雪佛龙`，日K，横轴约为2020年
12月至2021年4月。图中已标出 A、L、B，并以青色水平线画出L颈线。

### 按图理解结构

1. **候选外观存在**：价格先上行形成A，回撤形成L，随后反弹形成接近A高度的B；因此可以先
   标注为 `A—L—B 的M顶候选`，而不能因双峰外观立即称为M顶。
2. **L是分界线**：L的低点画出的水平颈线约位于81—82区域。B后价格回撤靠近该线，但日K没有
   以收盘价收在L低点下方。
3. **结果不是破位而是支撑**：颈线没有被收盘跌破，反而承接了回撤；价格随后转为强劲上行，
   并越过此前A、B区域。

### 与规则逐项对应

| 观察项目 | 本例结果 | 正确状态 |
| --- | --- | --- |
| A—L—B外观 | 存在 | M顶候选，不等于已形成 |
| B后回撤至L颈线 | 存在 | 颈线测试 |
| 后续收盘 `close < L.low` | 未出现 | **不确认M顶** |
| 颈线角色 | 回撤后未失守 | 支撑得到验证 |
| 后续价格演化 | 向上越过A、B区域 | 候选结构终止，转为新的上行结构观察 |

### 此例要记住的判读边界

- `A—L—B` 只说明需要关注M顶的可能性；**收盘跌破L颈线**才是M顶成立条件。
- 对颈线的盘中接近、触及甚至影线短暂刺穿，均不能替代收盘确认。
- 未破颈线时，颈线仍是支撑；本例正是支撑后上行的反例，不能把它误报为“失败的M顶”或
  “已确认后失效的M顶”，而应记录为“未确认候选，随后演化为上行”。

## 一、组合构成（字幕 01:50—04:39）

启明星是连续三根K线的底部组合形态，而不是单根K线：

```text
A：下跌的阴线／红色K线
B：十字K（涨跌颜色不重要；实体很小、上下影线都较长）
C：上涨的阳线／绿色K线
```

- A 必须是阴线，C 必须是阳线。
- B 的颜色不是条件；其核心是小实体与双侧较长影线。若仅一侧影线特别长，可能是锤子或倒锤子，而不是本课要求的十字K。
- 本课程的色彩约定为红/橙代表下跌、绿代表上涨；识别时应以开收盘关系而非软件配色为准。

## PPT 留档 01｜启明星四要素：组成（视频约04:11）

### PPT 原文

```text
K线技术见底形态之五：启明星 四要素

1.组成：由连续三根K线的组合形态构成

阴线（下跌）A
十字星线（颜色不限，实体很小，有影线）B
阳线（上涨）C
```

### 图示的文字化理解

- 从左到右是连续的 `A → B → C`，不是可隔日抽取的三根K线。
- A 为较大的下跌实体；C 为较大的上涨实体。两者颜色/方向是构成条件，截图以橙、绿作示意，不应把颜色名称当作唯一识别方式。
- B 画成极小的横向实体，且在实体上下均有影线；PPT的最低文字要求是“颜色不限、实体很小、有影线”。字幕进一步把标准十字K解释为上下影线都较长；两层信息均保留，后续PPT若给出比例或例外，以PPT为准。
- 画面中C的实体明显高于B，表达第三根需以上涨阳线给出反转尝试；本页尚未定义C相对A实体上沿的收盘价条件，该条件留在下一页的价格要素核对。

### 可程序化锚点

```text
consecutive_order = [A, B, C]
A = bearish / close < open
B = doji_or_star; body very small; color unrestricted; has shadows
C = bullish / close > open
```

## 二、位置与C的价格硬条件（字幕 04:39—09:02）

- A、B、C 必须出现在**明显下行趋势**中。趋势允许短暂反弹或下跌后的横盘整理；只要整体低点持续走低、上方旧高不能突破，下行趋势尚未改变。横盘而无下行背景不适用。
- C 是阳线，其实体上沿为收盘价；A 是阴线，其实体上沿为开盘价。
- 本课采用的强化判定是：`C.close > A.open`，即 C 收盘必须严格高于 A 实体上沿／开盘价。
- “C只深度进入A实体、但未超过A开盘价”的教材版本，讲师认为误判较多；本期以 `C.close > A.open` 为准，不放宽成“进入A实体即可”。

## PPT 留档 02｜位置、C收盘价与成交量（视频约10:10）

### PPT 原文

```text
2.位置：出现在明显的下行趋势中。
3.形成：阳线C收盘价，高于A开盘价。
4.成交量：A、B没有要求。
          C成交量超过AB成交量的至少2/3，不能低于1/2
```

### 用户确认后的量能口径

这里的 “AB成交量” **不是** `max(A.volume, B.volume)`，也不是 A、B 成交量之和；它指
**A或B各自的成交量**。令：

```text
rA = C.volume / A.volume
rB = C.volume / B.volume

至少一项满足：rA > 2/3 或 rB > 2/3
同时两项都不得低于：rA >= 1/2 且 rB >= 1/2
```

换言之，C只要高于A或B中任意一根的2/3即可达到主要量能要求；但C相对A、B任一根都不能
低于1/2。A、B本身之间没有成交量高低要求。

- C量若分别高于A、B，则是更强的上涨力量证据，但不是额外硬条件。
- 若C低于A或B其中任一根的1/2，按本课记为无效／虚假信号。
- 该规则与黄昏之星不同：黄昏之星的C量能要求大于A、B；本期启明星不要求C大于A、B，只按上述 `2/3` 与 `1/2` 门槛核验。

## 四、质量、意义与待核实的失效口径

- B 相比 A 出现向下跳空的十字K，是讲师所称“最好的”形态变体；没有跳空仍可形成启明星。
- 启明星是底部止跌／可能见底信号，其警示强度略弱于此前课程中的锤子线、倒锤子线；它不保证反转。
- 课程将形态防守位描述为 A、B、C 三根K线中**最低低点**，并明确包含下影线；无额外成交量要求。
- 字幕约18:43称后续D K“跌破”A/B/C最低点即止损；约19:36进一步说“收盘收在ABC最低点（含影线）下方”代表形态失败。因此正式写入前，需以PPT或用户明确的“触及/盘中/收盘”口径确定；不能沿用其他课程的失效口径。

## 七、结课写入摘要（用户确认）

本期已按用户授权写入 RaModel，且仅新增 `morning_star_assessment`；不改写锤子线、倒锤子线、看涨抱线、W底、头肩底或任何其他模型。

- 连续三根日K：`A阴线 → B颜色不限的小实体有影线十字/星线 → C阳线`，且须位于明确下行趋势。
- `C.close > A.open` 是本课硬性价格条件；B向下跳空仅为更强变体。
- 量能严格逐根比较：`rA=C.volume/A.volume`、`rB=C.volume/B.volume`；`max(rA,rB)>2/3` 且 `min(rA,rB)>=1/2`。A/B不相加、不取最大值，彼此也无量能关系。
- 后续只在常规收盘严格低于 `min(A.low,B.low,C.low)`（含影线）时记录失效；盘中低破单列为测试，失效无量能附加条件。
- 仅输出结构、量能、后续状态和案例证据，不输出任何交易行动、目标价、止损或仓位。
